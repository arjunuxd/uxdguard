# Security Policy

## Reporting Vulnerabilities

Report security issues responsibly via GitHub issues or to the repository maintainers. Do not disclose vulnerabilities publicly until they have been reviewed and addressed.

## Supported Versions
Only the latest main branch is supported.

## Security Practices
- No automatic network operations in core scanning
- No code execution
- Explicit process arguments only
- Secrets redacted from outputs
- Safe hook installation
- Local-first by design
